Pipelines can now be written in [Beam YAML](https://github.com/ardada2468/beam-agents/blob/main/docs/yaml.md): declare a `python` provider mapping `RunAgent` to `beam_agents.yaml.run_agent`, name your agent and provider factory with `module:object` references, and the transform keys and envelopes your rows for you and returns `output`/`intents`/`traces`/`errors` as addressable named row streams. References resolve at document-expansion time, so a typo'd module, a missing attribute, or an unknown config key fails before the pipeline is submitted rather than inside a bundle.
