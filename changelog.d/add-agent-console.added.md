A local console for watching agents run. `beam-agents-console` serves a browser UI over the trace, error, and snapshot records the runtime already emits — activations, span trees, errors grouped by reason, per-model token spend, per-tool failure rates, and the approval queue — backed by a single SQLite file that needs no broker and no cloud project. Records reach it five ways: a new `console://` sink scheme via `ConsoleSinkResolver`, the OTLP endpoint an existing `otlp://` pipeline already posts to, a consumer over a Kafka topic you already export to, a reader over a BigQuery table you already write, or an import of the capture files `beam-agents-replay` consumes. `docker compose -f docker/compose.console.yaml up` starts it with a demo pipeline already feeding it.
