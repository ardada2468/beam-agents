Side effects execute **outside** the pipeline, in a separate service:
`intents → dedup → execute → results → re-injection`. The effector shipped here
is a reference implementation, not a hosted product, and it is installed from
the `effector` extra.

<Example file="intents_and_resume.py" region="agent" />

Read the guarantees section below carefully. The honest statement is bounded:
duplicates are bounded to the crash window between a tool's effect and its
durable completion record, and true exactly-once requires tools that are
idempotent on `intent_id`. The end-to-end semantics gate exercises exactly that
— SIGKILLed effector workers, a killed TaskManager, and a full replay over
10,000 events.
