The capability specs the implementation is written against live under
`openspec/specs/` in the repository. A handful have a dedicated page in this
section, rendered verbatim. The rest — most of them promoted from archived
change folders as part of the 1.0 consolidation — are listed here by path
rather than summarized, because a summary that drifts is worse than a link
that does not.

Each name links to the spec file itself on the `main` branch. The requirements
are stated there in `SHALL` form, scenario by scenario; nothing on this page
adds to or interprets them.

## Not yet implemented

This page is marked **partial** on purpose: it is an index, not coverage. Each
row is a capability spec that has not yet earned a rendered page in this
section. The site's own verifier keeps the list honest — a spec under
`openspec/specs/` fails the build until some page here names it, and this page
is where one lands until it gets a better home.
