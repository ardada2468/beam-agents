Two activations, one logical unit of work. `ctx.act` stages the intent and returns its
deterministic id; `Suspend` persists the continuation and arms the fail-closed timeout.

The example can name the intent id *before* the pipeline runs, because the id is
`uuid5(namespace, key|seq|step_index)` — a pure function of the activation's position.
That is what makes deduplication a lookup rather than a guess.

Run it:

```sh
uv run python website/examples/intents_and_resume.py
```
