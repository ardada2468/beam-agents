Two keys take two paths: one approval arrives, the other never does. The silent key's
HITL timer fires and the policy routes it to a deterministic denial.

Processing time is advanced by the test stream rather than by sleeping, so both clocks
are scripted and the outcome is deterministic — the same technique the repository's own
timer tests use.

Run it:

```sh
uv run python website/examples/human_in_the_loop.py
```
