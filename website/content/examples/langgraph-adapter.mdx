Three changes, none to the graph's shape: re-tag side-effecting tools, swap `ToolNode`
for `BeamToolNode`, and wrap the graph in `LangGraphAgent`.

This example requires the `langgraph` extra. Without it installed, the repository's test
suite skips it with a stated reason rather than failing.

<Callout>
This example needs the `langgraph` extra: `uv sync --extra langgraph`.
</Callout>

Run it:

```sh
uv run python website/examples/langgraph_adapter.py
```
