Three keys down three paths in one bounded pipeline, with assertions on every stream.

The trace assertion is worth reading closely. A committed activation emits its whole
span set; the failed one emits a single `ERROR` event, because the spans it staged
before raising were discarded along with its memory write. Atomic commit, visible from
outside the runtime.

Run it:

```sh
uv run python website/examples/four_outputs.py
```
