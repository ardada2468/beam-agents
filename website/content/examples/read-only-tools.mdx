Tools split in two by their `side_effect` flag, and the split is enforced rather than
advised: a read-only tool runs inline via `ctx.run_tool`, and a `side_effect=True` tool
raises if called directly.

The example asserts on the refusal itself, so the guarantee is demonstrated rather than
asserted in prose.

Run it:

```sh
uv run python website/examples/read_only_tools.py
```
