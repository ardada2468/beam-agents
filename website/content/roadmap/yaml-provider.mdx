The module map lists a `yaml/` provider, which would let `RunAgent` be used from a Beam
YAML pipeline definition rather than from Python.

**What exists today:** no such package.

Pipelines are constructed in Python, and the agent itself must be a module-level Python
callable so it pickles by reference for the runner.
