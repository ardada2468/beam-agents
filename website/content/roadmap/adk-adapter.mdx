Nothing on this page exists in the current code. `src/beam_agents/adapters/adk/` is not present in the
repository. This is a description of intent, published so the project's direction is
legible — not documentation of a feature you can use.

The module map lists `adapters/adk` alongside the LangGraph adapter.

**What exists today:** `src/beam_agents/adapters/` contains `langgraph/` and nothing else.
There is no `adk` package, no `adk` extra in `pyproject.toml`, and no ADK row in the
conformance matrix.

The adapter contract itself is real and structural — an adapter targets the runtime driver
protocol, and the conformance matrix runs seven lifecycle scenarios against every
*registered* adapter across two runners. An ADK adapter would have to pass that matrix. It
does not exist to pass it.

See [adapters](/comparison/adapters) for what is implemented.
